# Dhoria Academy Gwadar

Official website and administrative management portal for **Dhoria Academy Gwadar** in Balochistan, Pakistan.

## 🌟 Features
- **Public Institutional Website**: High-performance, mobile-responsive portal detailing academic programs, admissions, faculty, community events, and visitor archives.
- **Admin Control Panel** (`/admin/login.html`): Secure administrative system for managing site settings, hero announcements, articles, and staff records.
- **Tuition-Free Education**: Highlighting 20+ years of voluntary education and skill development in Gwadar.

## 🔗 Portals
- **Public Website**: `/index.html`
- **Admin Login**: `/admin/login.html`
- **Default Admin Credentials**: `admin` / `admin123`
